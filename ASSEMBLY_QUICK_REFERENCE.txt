┌───────────────────────────────────────────────────────────────────────────┐
│ POWER SETUP (Do this FIRST!)                                              │
├───────────────────────────────────────────────────────────────────────────┤
│ RED RAIL (5V)           ← USB 5V or Power Bank                            │
│ BLUE RAIL (GND)         ← USB GND or Power Bank GND (2x connections!)    │
│                                                                           │
│ Verify: Multimeter between RED-BLUE = 5V (no shorts!)                   │
└───────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────┐
│ ESP32 PLACEMENT (Center of breadboard)                                    │
├───────────────────────────────────────────────────────────────────────────┤
│ [ ] ESP32 VIN  → RED RAIL (5V)                                            │
│ [ ] ESP32 GND  → BLUE RAIL (2x connections!)                             │
│                                                                           │
│ Left side pins        │ Right side pins                                  │
│ GND → GND Rail       │ 3V3 → 3.3V (if separate)                         │
│ EN  → (leave open)   │ D4  → DHT22 DATA                                 │
│ D12 → Relay IN       │ D2  → Red LED                                    │
│ (others unused)      │ D5  → Green LED                                  │
│                      │ D18 → Yellow LED                                 │
│                      │ D21 → BMP280 SDA                                 │
│                      │ D22 → BMP280 SCL                                 │
│                      │ D13 → Servo PWM                                  │
│                      │ D34 → Rain Analog                                │
│                      │ D35 → Rain Digital                          │
└───────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────┐
│ SENSOR CONNECTIONS                                                        │
├───────────────────────────────────────────────────────────────────────────┤
│                                                                           │
│ DHT22 (Temperature & Humidity)                                           │
│ ├─ VCC     → 3.3V (with 10K pullup resistor!)                           │
│ ├─ DATA    → GPIO 4 (D4)                                                │
│ └─ GND     → BLUE RAIL                                                  │
│                                                                           │
│ BMP280 (Pressure - I2C)                                                 │
│ ├─ VCC     → 3.3V                                                       │
│ ├─ GND     → BLUE RAIL                                                  │
│ ├─ SDA     → GPIO 21 (D21)                                              │
│ └─ SCL     → GPIO 22 (D22)                                              │
│                                                                           │
│ Rain Sensor (Analog + Digital)                                          │
│ ├─ VCC     → 5V or 3.3V (check module!)                                │
│ ├─ GND     → BLUE RAIL                                                  │
│ ├─ AOUT    → GPIO 34 (Analog)                                           │
│ └─ DOUT    → GPIO 35 (Digital)                                          │
│                                                                           │
│ Status LEDs (3 total)                                                   │
│ ├─ Red LED    → GPIO 2 (D2) + [220Ω resistor] → GND                    │
│ ├─ Green LED  → GPIO 5 (D5) + [220Ω resistor] → GND                    │
│ └─ Yellow LED → GPIO 18 (D18) + [220Ω resistor] → GND                  │
└───────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────┐
│ ACTUATORS (Motion Control)                                                │
├───────────────────────────────────────────────────────────────────────────┤
│                                                                           │
│ Servo Motor (Window Control)                                            │
│ ├─ Red wire    → 5V RAIL                                                │
│ ├─ Black wire  → BLUE RAIL (GND)                                        │
│ ├─ Yellow wire → GPIO 13 (D13)                                          │
│ └─ Mount: Attach to window latch for 90° rotation                      │
│                                                                           │
│ Relay Module (Irrigation Control)                                       │
│ ├─ VCC  → 5V RAIL                                                       │
│ ├─ GND  → BLUE RAIL                                                     │
│ ├─ IN   → GPIO 12 (D12)                                                 │
│ └─ COM/NO → Connect to pump (separate 12V circuit!)                    │
│   ⚠️  CRITICAL: Keep pump power AWAY from ESP32!                        │
└───────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────┐
│ RESISTOR VALUES - CHECK THESE!                                           │
├───────────────────────────────────────────────────────────────────────────┤
│ [ ] 10K pullup resistor → DHT22 VCC line (100% MUST HAVE)               │
│ [ ] 220Ω resistors (x3) → Each LED cathode to GND                       │
│ [ ] 10K resistors (x2, if needed) → BMP280 I2C lines (check module)    │
│                                                                           │
│ Resistor Color Code (for verification):                                 │
│ ├─ 10K = Brown-Black-Orange                                             │
│ └─ 220Ω = Red-Red-Brown                                                 │
└───────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────┐
│ TESTING AFTER ASSEMBLY                                                    │
├───────────────────────────────────────────────────────────────────────────┤
│ STEP 1: Power-on test (WITHOUT code uploaded)                           │
│ ├─ [ ] Connect USB to ESP32                                             │
│ ├─ [ ] Green LED lights up?                                             │
│ └─ [ ] No burn smell? ✓ Safe to continue                                │
│                                                                           │
│ STEP 2: Visual inspection                                               │
│ ├─ [ ] No loose wires                                                   │
│ ├─ [ ] No copper touching copper (shorts)                               │
│ ├─ [ ] Jumper wires properly inserted                                   │
│ └─ [ ] Sensors sitting level (not tilted)                               │
│                                                                           │
│ STEP 3: Multimeter verification                                         │
│ ├─ [ ] RED-BLUE rails = 5V (not higher!)                                │
│ ├─ [ ] GPIO pins float around 3.3V (normal)                             │
│ └─ [ ] No continuity between RED and BLUE                               │
│                                                                           │
│ STEP 4: After code upload (in Serial Monitor)                          │
│ ├─ [ ] Temperature reading = reasonable temp                            │
│ ├─ [ ] Humidity reading = 30-80%                                        │
│ ├─ [ ] Pressure reading = ~1013 hPa                                     │
│ └─ [ ] Rain sensor responds to moisture                                 │
└───────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────┐
│ QUICK TROUBLESHOOTING                                                     │
├───────────────────────────────────────────────────────────────────────────┤
│ Green LED off after power?                                               │
│ └─ Check: RED and BLUE rail connections (most common issue!)            │
│                                                                           │
│ DHT22 reads -1?                                                          │
│ └─ Check: 10K pullup resistor and GPIO 4 connection                     │
│                                                                           │
│ BMP280 not found?                                                        │
│ └─ Check: GPIO 21 & 22, I2C address (0x76 vs 0x77)                    │
│                                                                           │
│ Servo doesn't move?                                                      │
│ └─ Check: GPIO 13 and 5V power to servo                                 │
│                                                                           │
│ Relay doesn't click?                                                     │
│ └─ Check: GPIO 12 and relay module 5V power                             │
└───────────────────────────────────────────────────────────────────────────┘
