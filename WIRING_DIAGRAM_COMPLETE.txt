│  ════════════════════════════                                              │
│  VCC ──→ 5V (Logic power)                                                  │
│  GND ──→ GND                                                               │
│  IN ──→ GPIO 12 (D12) [Control pin]                                       │
│  COM ──→ Pump/Load Common                                                 │
│  NO ──→ Pump/Load Positive                                                │

│                                                                             │
│  Wiring Diagram:                                                           │
│  ═════════════════                                                         │
│                                                                             │
│   Power Supply (12V)                                                       │
│        │                                                                   │
│        ├──→ [PUMP] ──→ LOAD RETURN ──→ GND                                │
│        │                                                                   │

═══════════════════════════════════════════════════════════════════════════════
                            POWER DISTRIBUTION
═══════════════════════════════════════════════════════════════════════════════

Option A: USB Power (Development)
─────────────────────────────────
    USB Adapter (5V, 2A)
          │
          ├─ ESP32 Micro USB Port
          └─ Breadboard 5V Rail for sensors/servo

Option B: External Power Supply (Recommended)
──────────────────────────────────────────────
    5V Power Bank (5V, 2A+)
          │
          ├─ Breadboard RED Rail (5V)
          ├─ Breadboard BLUE Rail (GND)
          └─ Add 10µF capacitor across power for stability

Option C: Dual Power (High Power Devices)
──────────────────────────────────────────
    USB (5V, 1A) ──→ ESP32 + Sensors (logic)
    12V Supply (5A) ──→ Pump/Relay (high current)
    
    ⚠️  CRITICAL: Connect GND of both supplies together!

═══════════════════════════════════════════════════════════════════════════════
                            COMPLETE ASSEMBLY
═══════════════════════════════════════════════════════════════════════════════

Step-by-step assembly order:

1. Mount ESP32 on breadboard center
2. Connect power rails (GND, 5V, 3.3V)
3. Add DHT22 with pullup resistor
4. Add BMP280 I2C with pullups
5. Add Rain sensor (analog + digital)
6. Add status LEDs with 220Ω resistors
7. Add Servo motor (separate 5V)
8. Add Relay module (separate 5V for pump)
9. Connect USB power for testing
10. Load ESP32_SENSOR_CODE.ino
